# 알바 급여 계산기

2026·2027년 최저시급 기준으로 알바 급여를 계산하는 웹 계산기입니다.
웹은 가벼운 HTML로 서비스하고, Flutter 코드는 이후 교대근무 캘린더 앱에서 재사용합니다.

**👉 바로 사용하기: https://rftgy1029.github.io/alba-pay-calculator/**

## 기능

- 기준 연도 선택 (2026 / 2027)
- 시급, 하루 근무시간, 야간 시간(22~06시), 주 근무일수 입력
- 주휴수당 (주 15시간 이상)
- 5인 이상 사업장의 연장·야간 가산수당 (50%)
- 공제: 없음 / 3.3% / 4대보험 → 월 실수령액
- 주급·월급 동시 표시 (월 환산 = 주 × 365/7/12, 주 40시간 → 월 209시간)
- 결과 공유 링크 (입력값이 주소에 담겨서, 링크를 열면 같은 계산이 복원됨)

## 구조

| 폴더 | 용도 |
|---|---|
| `site/` | **웹 사이트 (배포 대상)**: `calc.js` 계산 로직, `app.js` 화면 동작, `index.html` 화면·설명 글 |
| `lib/`, `test/` | Flutter 앱용 계산 로직·화면 (`lib/pay_calculator.dart`는 `site/calc.js`와 같은 규칙) |

계산 규칙을 바꿀 때는 `site/calc.js`와 `lib/pay_calculator.dart`를 함께 고칩니다.

## 실행

```bash
# 웹 계산 로직 테스트
cd site && node --test calc.test.js

# 웹 로컬 미리보기 → http://localhost:8787
python3 -m http.server 8787 --directory site

# Flutter 테스트
flutter test
```

## 배포

`main`에 푸시하면 GitHub Actions가 웹 계산 로직 테스트 후 `site/` 폴더를 GitHub Pages에 배포합니다
(`.github/workflows/deploy-pages.yml`). 테스트가 실패하면 배포되지 않습니다.

## 기준값

| 항목 | 2026년 | 2027년 |
|---|---|---|
| 최저시급 | 10,320원 | 10,700원 |
| 국민연금 (근로자) | 4.75% | 5% |
| 건강보험 (근로자) | 3.595% | 3.595% (동결) |
| 장기요양보험 | 건강보험료 × 13.14% | 미확정 → 2026년 요율 적용 |
| 고용보험 (근로자) | 0.9% | 미확정 (1.0% 인상안 논의 중) → 2026년 요율 적용 |

2027년 장기요양·고용보험 요율이 확정되면 `site/calc.js`의 `YEARS[2027]`을 고치고 `pending`에서 빼면 됩니다.
계산 결과는 참고용이며, 근로소득세(간이세액)는 아직 포함하지 않습니다.
